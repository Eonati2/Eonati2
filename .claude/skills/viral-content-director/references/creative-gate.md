# Gate C — creative quality, with veto power

Gate C exists because of a specific failure in this toolkit's own history: a render
scored hook-energy 1.01, loop "seamless", grade in range — every number green — and the
contact sheet showed a grey diamond lattice instead of a sky. Metrics cannot see ugliness.

**Look first.** Run `scripts/inspect_visual.py` and read all four images before scoring.
Scoring from memory of the render is how this gate gets quietly skipped.

## The catastrophe question

> **Does this look like the thing it was supposed to be?**

Compare the render against the visual concept written in phase 6. If it does not depict
that thing, **stop — nothing else matters.** Do not adjust the grade or re-cut. The cause
is upstream: the concept or the footage source. Procedural synthesis pretending to be
photoreal cinematography is the recurring version of this.

## Score /10

| Criterion | Fails when |
|---|---|
| Beauty | you would not stop for it in someone else's feed |
| Realism | textures, light or physics read as fake when they shouldn't |
| Composition | subject is placed carelessly; no visual hierarchy |
| Emotional impact | technically fine, feels like nothing |
| Originality | indistinguishable from a thousand other clips |
| Visual coherence | shots look like they came from different videos |
| Cinematic quality | reads as a screensaver, a template, or a slideshow |
| Platform-native | reads as an ad or an AI artifact, not as content |

**Any single score of 4 or below is a veto**, regardless of the total. One badly broken
dimension is what viewers actually notice.

## Ranking generated footage

Never auto-accept candidate #1. Generate several; score each on realism, composition,
motion quality, subject quality, lighting, emotional impact, visual novelty, usability,
continuity.

Reject outright, whatever else scores well: warped anatomy · impossible motion · plastic
texture · lighting that contradicts the scene · camera moves no operator would make ·
flicker or morphing artifacts · generic stock composition · visual noise with no subject.

A technically valid generation is not automatically acceptable footage.

## Saying no

When Gate C fails, say it plainly: what failed, at which timestamp, and which upstream
decision caused it. "Passes A and B, fails C on realism and coherence — the sky reads as
procedural noise, so the footage source is wrong, not the grade." Then fix that, not the
symptom.
