# The Conditional Question Framework

> Default cold first-touch CTA. Replaces "compare notes" / "open to a quick call" / "would you have 15 minutes." Removes commitment, previews value, and sorts replies.

## Why it works

Recipients usually land in one of three buckets:

1. **Yes** (rare)
2. **No** (majority)
3. **Maybe, but not ready to commit** (large middle)

A hard meeting ask collapses #3 into #2. The Conditional Question keeps #3 alive:

> **"If I could [verb] you [specific value], would that be [useful / valuable / something to consider]?"**

## Three variants

### A — "Show you" (demo / comparison)

```
If I could show you how [solution] handles [specific issue], would that be something to consider?
```

**Example (fictional SaaS):**
```
If I could show you how we cut weekly campaign QA from 4 hours to under 20 minutes with a Claude skill pack, would that be something to consider?
```

### B — "Share insight" (expert-respectful)

```
If I could share [insight or comparison], not sure if your team has already mapped this, would that be useful?
```

**Example:**
```
If I could share the reply-rate patterns we see when teams ban fluff openers and force a Conditional Question CTA, not sure if you've already mapped this, would that be useful?
```

### C — "Send you a [asset]" (async value)

```
If I could send you the [framework / audit / checklist], would that be useful for [planning / eval]?
```

**Example:**
```
If I could send you the cold-email pre-send checklist we use before any Instantly launch, would that be useful for your next campaign?
```

Only use Variant C if the asset exists (or can ship within 24 hours of a yes).

## Failure modes

1. **Vague** — "If I could share some thoughts…" (no preview)
2. **Conditional + meeting** — defeats the point; drop the calendar ask
3. **Meeting in disguise** — "If I could walk you through this on a 15-minute call…"
4. **Run-on** — keep the ask to one tight sentence
5. **Banned phrases** — never pair with "compare notes"

## Reply handling

| Reply | Do |
|-------|----|
| Yes / send it | Deliver the asset same day. No meeting ask in that email. |
| What is it? | 2–3 sentence preview; reaffirm send offer |
| No | Thank and suppress. Do not send the asset anyway. |
| OOO | Re-send after return; do not count as engagement |

## Simple 4-touch skeleton (business-agnostic)

**Email 1** — Hook + Conditional Question  
**Email 2 (Day 4–7)** — New factual insight (not "just following up") + soft re-offer  
**Email 3 (Day 10–14)** — New subject / new angle  
**Email 4 (Day 18–21)** — Breakup with low-friction reply codes (e.g. "GS" / "NT")

Email 2 must add value. Never write "checking in" or "making sure this didn't get buried."

## When to break the framework

- Clear public pain just happened (outage, layoff, product EOL) — lead with that insight
- Prospect asks for a calendar link directly
- The promised asset is not ready
